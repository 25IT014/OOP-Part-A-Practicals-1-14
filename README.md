## About This Repository

This repository contains the Part-A practice programs (Practical 1–14) for the Object Oriented Programming (CEUE203) course.

It covers Java programming concepts through practical exercises, including classes, objects, encapsulation, inheritance, interfaces, exception handling, multithreading, file handling, collections, and generics.

**Note:** This README documents Part-A only. Part-B MiniBank project is not included.

## How to Compile and Run

Open the terminal in the folder containing the Java source file.

**Compile:**

```bash
javac FileName.java
```

**Run:**

```bash
java ClassName
```

For programs containing multiple Java files:

```bash
javac FileName.java Driver.java
java Driver
```
